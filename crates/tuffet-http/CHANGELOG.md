## [0.1.0] - 2026-11-03

### Added

- First release: `HttpTransport`, an HTTP(S) transport for `tuffet` built on
  reqwest.
- Features `aws-lc-rs` (default: rustls and AWS-LC) and `native-tls` (the
  platform's TLS and RustCrypto).
